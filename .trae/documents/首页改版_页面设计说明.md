# 首页改版（Desktop-first）页面设计说明

## 1) Layout（布局与响应式）
- 框架：Desktop-first，最大内容宽度 1120–1200px，左右留白自适应；全宽背景 + 居中内容容器。
- 布局方式：整体采用“纵向分区堆叠（stacked sections）”；分区内部使用 CSS Grid + Flex 混合。
  - 顶部导航：Flex（左右分布、菜单横排、可折叠入口在小屏出现）。
  - 首屏：Grid（左文案右留白/装饰图可选，若无图则居中文案）。
  - 主体：Grid 两列（文章列表主列 + 标签云侧栏），在 <= 960px 断点折叠为单列（标签云下移到文章列表上方或下方，二选一保持一致）。
- 断点建议：
  - >=1200px：两列布局（文章 8/12，标签 4/12）。
  - 960–1199px：两列但侧栏更窄（文章 9/12，标签 3/12）。
  - <960px：单列，导航简化、吸顶可降级。

## 2) Meta Information（页面元信息）
- Title：`{站点名} | 首页`
- Description：一句话概述站点内容与主题（保持现有 SEO 文案策略；如现有已配置则沿用不改）。
- Open Graph：
  - og:title 同 Title
  - og:description 同 Description
  - og:type = website
  - og:url = 当前站点根路径

## 3) Global Styles（全局样式与设计令牌）
- 色彩（极简）：
  - Background：#FFFFFF / #0B0F14（若站点已有暗色主题则仅做兼容，不强制新增）
  - Text Primary：#111827
  - Text Secondary：#6B7280
  - Border：#E5E7EB（1px）
  - Accent（主色）：沿用现有品牌色（用于按钮、链接、选中标签态）
- 字体：沿用现有字体栈；字号层级（示例）：
  - H1 40/48，H2 24/32，Body 16/24，Caption 13/20
- 按钮：
  - Primary：实心主色，hover 亮度 +6%，active -6%，圆角 10–12px
  - Ghost：透明底 + 边框，hover 轻背景
- 链接：正文内下划线或 hover 下划线；导航采用底部 2px 指示条作为当前态。
- 动效：150–220ms ease-out；尊重 `prefers-reduced-motion` 关闭进入动效/平滑滚动。

## 4) Page Structure（页面结构）
1. 顶部导航（现有结构）
2. 首屏 Hero（站点定位 + CTA）
3. 主内容区（文章列表 + 标签云）
4. 页脚（沿用现有）

## 5) Sections & Components（区块与组件细化）

### 5.1 顶部导航（兼容现有）
- 组成：站点 Logo/名称、导航项（现有）、可选右侧功能位（若现有有则保留）。
- 交互：
  - 当前页高亮（首页）
  - hover 状态（颜色/底线/背景轻提示）
  - 轻量吸顶：滚动超过 Hero 底部后启用半透明背景 + 轻阴影（移动端可关闭）。

### 5.2 Hero（首屏）
- 左侧：
  - H1：站点名或主标题
  - Subcopy：一句话定位（不超过 2 行）
  - CTA：按钮“查看最新文章”（锚点到文章列表区）
- 右侧（可选）：极简装饰（纯色块/线条/渐变，不影响加载）。如现有首页无图资源，默认不放图。

### 5.3 文章列表区（兼容现有列表）
- 标题行：`最新文章` + 当前筛选标签（如有）+ “清除筛选”。
- 列表样式：卡片列表（纵向），卡片内保持现有字段展示顺序（标题、摘要、日期/标签等以现有为准）。
- 交互：
  - 卡片 hover：轻抬升（1–2px）+ 阴影淡入；点击进入文章详情（现有链接）。
  - 列表进入视口：淡入/上移 6px（可降级）。

### 5.4 标签云侧栏（兼容现有标签云）
- 标题：`标签`
- 展示：流式换行的标签 pill（Flex wrap），按现有标签集合与排序策略渲染。
- 状态：
  - 默认：浅边框
  - hover：浅背景
  - 选中：主色描边或浅主色底 + 对勾/高亮（保持极简）
- 行为：点击标签触发文章列表本地筛选；再次点击取消；提供“清除筛选”。

### 5.5 空态/加载态/错误态
- 空态：当筛选无结果，显示“未找到相关文章”+ “清除筛选”。
- 加载态：骨架屏（若现有已有则沿用）；避免整页抖动。
- 错误态：简短提示 + 重试入口（仅在现有逻辑支持时展示）。
