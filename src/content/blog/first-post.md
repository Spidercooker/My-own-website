## 为什么选择自动化构建？

通过 GitHub Actions 和 Astro，我不再需要手动修改复杂的 HTML 代码。

### 核心优势：
1. **纯文本写作**：只需专注于内容，使用 Markdown 格式。
2. **自动部署**：推送到 GitHub 后，网站会自动更新。
3. **性能卓越**：Astro 生成的网页速度极快。

### 如何写新文章？
只需在 `src/content/blog/` 目录下创建一个新的 `.md` 文件，填写好顶部的元数据（Frontmatter），剩下的交给 GitHub 就好了！

```markdown
---
title: "文章标题"
description: "文章摘要"
pubDate: "2026-03-19"
---
这里是内容...
```
